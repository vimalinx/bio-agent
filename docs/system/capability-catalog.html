Capability Catalog

This page documents how bio-agent now separates productized hero lanes, bridge-executable tool surfaces, and reference-only planning/catalog coverage.

The catalog is derived from evidence-bearing metadata instead of raw skill counts: workflow registries, benchmark registries, and discovered skill/runtime metadata.

first_party_executable bridge_executable reference_only execution_tier runtime_mode verification_level reproducibility_level source_kind

Vocabulary

first_party_executable

Productized hero workflows surfaced via the canonical session/run control plane.

bridge_executable

Runnable tool/skill bridges discovered locally, but not yet packaged as first-party product lanes.

reference_only

Grounded workflow families preserved for planning/reference honesty without a direct first-party execution promise.
