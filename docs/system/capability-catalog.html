Capability Catalog

这页把 `bio-agent` 的能力面拆成三层：first_party_executable、bridge_executable、reference_only。这样浏览 breadth 时不会把外部参考、桥接工作流、以及 repo 自己的控制面能力混成一个“都能本地跑”的 marketing 数字。

当前产品叙事是 control-plane-first hybrid：repo 自己负责 canonical session/run truth；hero lanes 通过 bridge surface 暴露更产品化的工作流入口；外部官方栈只作为 grounding/reference，不冒充一方可执行能力。
